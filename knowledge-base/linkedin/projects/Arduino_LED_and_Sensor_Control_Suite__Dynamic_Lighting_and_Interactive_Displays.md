# Arduino LED and Sensor Control Suite: Dynamic Lighting and Interactive Displays

**🗓️ Duration:** Sep 2020 – Dec 2020

**📄 Description:**

This comprehensive Arduino-based project showcases a variety of LED and sensor control techniques, creating an engaging blend of lighting effects and sensor-driven interactions. From RGB disco mode and user-customized blinkers to precise LED brightness control, each program adds a unique functionality to everyday electronics:  RGB Disco Mode: A vibrant RGB LED sequence to bring your surroundings to life with flashing colors. Smooth LED Brightness Control: A dynamic dimmable LED system, transitioning smoothly from 0 to 255 and back. Interactive Potentiometer & Buzzer: Adjust the LED brightness or buzzer tone by simply rotating a potentiometer. LDR Light Tracking: Real-time light level monitoring with the LDR, enhancing automation. User-Defined LED Blinker: Choose the number of times your LEDs should blink based on user input, bringing flexibility to your lighting setup. All built using Arduino, this project demonstrates how sensors and simple components can create interactive, customizable lighting and sensor displays.
