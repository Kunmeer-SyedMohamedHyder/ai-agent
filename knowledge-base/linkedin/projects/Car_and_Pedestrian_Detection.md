# Car and Pedestrian Detection

**🗓️ Duration:** Jan 2020 – Jun 2020

**📄 Description:**

Developed a Python-based object detection and tracking system that identifies and differentiates between pedestrians and vehicles in video footage. Utilizing OpenCV and machine learning models, the system processes video inputs, detects objects, and marks vehicles with one color-coded bounding box and pedestrians with another. This project demonstrates practical skills in computer vision, object detection, and real-time video processing.
