# Ansible Helm Chart: Instant Deployment of Controller-Target Architecture

**🗓️ Duration:** Feb 2024 – Jun 2024

**📄 Description:**

This project features a custom Helm chart that rapidly deploys an Ansible environment in Kubernetes, following a controller-target architecture. The chart spins up pods, where some act as Ansible controllers (masters) to manage automation tasks, and others serve as targets (workers) to execute those tasks. Designed for speed and simplicity, this solution allows for scalable, distributed automation in seconds, streamlining infrastructure management in a cloud-native setup.
