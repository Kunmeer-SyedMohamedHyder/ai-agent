# GUI Application Suite: A Collection of Tkinter Projects

**🗓️ Duration:** Jan 2020 – Sep 2020

**📄 Description:**

Developed a comprehensive suite of GUI-based applications using Python's Tkinter library, showcasing a range of functionality and interactive designs. This project consists of multiple small yet diverse applications, each demonstrating unique use cases and problem-solving approaches, from utility tools to fun games.  The applications include:  Rebase a Number: A script for converting numbers between bases. Calculator: A fully functional calculator with a user-friendly interface. Clock: A real-time clock displaying the current time. Dice Roller: A fun dice-rolling simulator with visual feedback. Feet to Metres Converter: A conversion tool that easily converts feet to metres. Image Viewer: A command-line image viewer with a Tkinter-based interface. Text Editor: A simple text editor with saving capabilities. Temperature Converter: A tool to convert temperatures with focused input fields. Tic-Tac-Toe Game: A classic XO game implemented with a graphical interface. User Data Management: A file for handling user data in various projects.  This suite of projects highlights my proficiency in creating intuitive and functional graphical user interfaces using Python, and it provides a variety of practical tools and entertaining games.
