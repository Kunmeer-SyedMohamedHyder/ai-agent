# QuickDeploy: Simplified Helm Chart for Apache Airflow

**🗓️ Duration:** Jan 2024 – Jul 2024

**📄 Description:**

This project involves developing a simplified Helm chart for deploying Apache Airflow, making it user-friendly and easy to set up within minutes. Unlike the more complex community Airflow Helm charts, this version eliminates unnecessary complications, offering a streamlined and accessible deployment process. Designed for users at all experience levels, this custom Helm chart ensures hassle-free configuration and faster spin-up of Airflow instances, enhancing workflow automation and task management in cloud-native environments.
