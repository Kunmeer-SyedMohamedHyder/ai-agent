# Real-Time Face Recognition System

**🗓️ Duration:** Feb 2021 – Mar 2021

**📄 Description:**

This project implements a real-time face recognition system that identifies individuals using a trained dataset of images. By leveraging machine learning algorithms, the system analyzes facial features from live camera input and matches them against the pre-trained dataset. Each person in the dataset has multiple images to enhance recognition accuracy under various lighting conditions and angles. The application highlights the recognized individual’s name on the screen, demonstrating practical applications in security, access control, and user interaction. This project showcases advanced capabilities in computer vision and artificial intelligence, contributing to seamless identification in real-world scenarios.
