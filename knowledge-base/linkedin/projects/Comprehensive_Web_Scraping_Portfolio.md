# Comprehensive Web Scraping Portfolio

**🗓️ Duration:** Apr 2021 – Aug 2021

**📄 Description:**

This project showcases an extensive collection of web scraping tasks performed across a wide variety of websites using Python and web scraping libraries such as BeautifulSoup, Scrapy, and Selenium. The scraped data spans different domains, including e-commerce platforms (Amazon, Walmart), sports websites (Premier League, AFL), financial sites (Yahoo Finance), and specialized platforms like Books to Scrape, accommodation websites, and more. These scraping scripts extracted valuable information like product details, prices, reviews, stock data, and sports statistics, saving data in formats such as JSON, CSV, and Excel for further analysis. This project highlights proficiency in automating data collection from diverse web sources.
