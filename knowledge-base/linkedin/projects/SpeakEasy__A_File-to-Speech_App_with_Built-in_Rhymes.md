# SpeakEasy: A File-to-Speech App with Built-in Rhymes

**🗓️ Duration:** Aug 2020 – Aug 2020

**📄 Description:**

Developed a user-friendly speaking app using Python's Tkinter to create an intuitive GUI that converts text files into speech. The app allows users to upload a file, which it then reads aloud, making it highly useful for accessibility or hands-free text consumption. For a fun touch, it comes preloaded with classic nursery rhymes like "Baa Baa Black Sheep" and "Twinkle Twinkle Little Star" for instant playback.  The interface is simple and efficient, ensuring smooth file uploads and clear voice output. This project demonstrates expertise in Python GUI design and text-to-speech conversion, enhancing user interaction with technology.
