# SwiftPlay: A Fast and Simple Custom MP3 Player Built with Python

**🗓️ Duration:** Jun 2020 – Aug 2020

**📄 Description:**

Designed a user-friendly MP3 player application using Python's Tkinter library. The player offers a simple and intuitive interface, allowing users to efficiently play, pause, and navigate through songs. Unlike other MP3 players, this custom solution is optimized for fast processing, ensuring minimal delay when loading and playing audio files.  Key features include:  Basic Controls: Play, pause, next, and previous song navigation. Real-Time Progress Display: A playtime progress bar to track the duration of each song. Optimized Performance: Faster song processing and playback compared to traditional MP3 players. This project showcases proficiency in Python's Tkinter for GUI development and audio handling with enhanced user experience in mind.
