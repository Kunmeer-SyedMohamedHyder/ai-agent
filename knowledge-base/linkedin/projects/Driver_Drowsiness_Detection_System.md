# Driver Drowsiness Detection System

**🗓️ Duration:** Sep 2021 – Sep 2021

**📄 Description:**

This project implements a real-time drowsiness detection system that monitors a driver’s eye landmarks using computer vision techniques. By analyzing eye movements and blinking patterns, the system determines if the driver is feeling sleepy or dozing off. If signs of drowsiness are detected, an alert is immediately raised to warn the driver and prevent potential accidents. This project demonstrates practical applications of machine learning and facial landmark detection for enhancing road safety.
